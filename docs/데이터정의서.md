# OpsMate 데이터정의서

실제 생성된 SQLite PRAGMA table_info 결과를 기준으로 총 9개 테이블의 필드와 단위를 정의한다. API 계층은 사용률 범위, 출처, 상태 전이와 역할을 검증한다.

## 공통 규칙

id는 자동 증가 정수이며 시각은 UTC ISO8601 문자열로 저장한다. 세션 만료는 epoch 밀리초다. 출처는 local, agent, demo로 구분하며 지표와 로그·장애에 함께 저장한다.

사용률은 백분율, 네트워크는 바이트/초다. 미수집 값은 null이며 0은 측정된 0을 뜻한다. 서버 이름과 계정명은 UNIQUE, 미해결 장애 active_key도 UNIQUE다.

세션과 수집 토큰은 원문 대신 SHA256 해시를 저장한다. 사용자 비밀번호는 무작위 salt와 scrypt로 저장한다. audit.actor는 계정명 스냅샷으로 외래키가 아니다.

## 관계와 보존 정책

users 1:N sessions, servers 1:N metrics·logs·incidents, incidents 1:N incident_events·analyses 관계다. 서버 물리 삭제 API는 없으며 비활성으로 보존한다. 해결한 장애의 active_key는 null로 바뀌어 재발을 새 행으로 저장한다.

지표와 로그는 7일 보존한다. 장애, 분석, 처리, 감사 이력은 자동 삭제하지 않는다. SQLite는 외래키와 WAL을 활성화한다. MariaDB 어댑터는 자동 증가 및 실수 타입을 변환하지만 DB 간 데이터 이관을 자동 수행하지 않는다.
