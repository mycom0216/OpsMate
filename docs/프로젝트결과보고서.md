# OpsMate 프로젝트결과보고서

OpsMate의 실행 가능한 로컬 관제 시스템, 자동 검증 및 한국어 제출물을 제작했다. 구현과 검증의 범위를 분리하고 추가 환경이 필요한 항목은 후속 작업으로 명시한다.

## 구현 결과

| 영역 | 구현 내용 | 현재 범위 |
| --- | --- | --- |
| 보안 | 로그인·RBAC·계정·감사 | 단일 인스턴스 |
| 수집 | 실제 호스트·에이전트·가상 분리 | OS 지원 범위 |
| 장애 | 임계치·로그·수집 중단·이력 | 운영자 수동 해결 |
| AI | BM25·임베딩·구조화 응답·인용 | 근거 제안·실행 없음 |
| 화면 | 실시간 관제·로그·보고서 | HTML CSS JavaScript |
| 제출 | 문서·도식·발표·SQLite 데모 | 형식·렌더 검사 증빙 |

## 측정 및 검증 결과

자동 검사 증빙은 test-output.txt, UI 검사 증빙은 ui-check.json에 보존한다. 검색 평가 Top1 및 Recall@3은 15개 자체 질의에서 각각 93%, 100%였다. 실제 Ollama 최종 모델 응답 계약 통과는 3/3다.

초기 수집 SQL 오류를 수정했고 CUDA 임베딩 오류는 CPU 실행으로 해결했다. 알려진 의존성 취약점은 수정 버전으로 갱신했다. 모델 출력은 근거 ID 및 구조를 검증하지만 원인 가설의 정답 여부를 보장하지 않는다.

## 배포 및 제출 상태

원격 저장소 상태: https://github.com/mycom0216/OpsMate 비공개 저장소 Commit Push 완료. 3516021 로컬·원격 HEAD 일치 및 GitHub Actions 전체 단계 통과. 최종 패키지의 SHA는 별도 최종검증 파일에 기록.

Docker 실기동: 실제 이미지 빌드 및 컨테이너 기동, 내부 HTTP 통합 검사 9개 통과. Windows 호스트 공개 포트 접속 미확인.

MariaDB 실기동: MariaDB 11.4 전용 검증 DB에서 스키마·초기화·API 왕복 9개 통과.

최종 ZIP과 Git에는 자격 증명, 실행 DB, .env, node_modules를 포함하지 않는다. 초기화 스크립트는 사용자 환경에서 새 비밀번호를 생성한다. 공개 데모 DB는 가상 지표만 포함하고 계정·토큰·세션은 비워 둔다.

## 미완료 및 후속 검증

독립 장애 데이터의 검색·원인 정확도, 대규모 동시 접속 및 장시간 안정성, 원격 TLS 프록시, 운영 백업 복구 훈련은 완료하지 않았다. Redis와 분산 세션, 원격 자동 복구는 구현 범위 밖이다.

Docker 앱과 MariaDB의 내부 통합 검사는 통과했지만 Windows 호스트 공개 포트 접속은 확인하지 못했다. 이 환경에서는 로컬 Node 실행으로 브라우저 관제를 검증했다.

실제 모델은 매뉴얼의 등록된 후보만 선택하지만 그 후보가 실제 장애의 원인인지 추가 확인해야 한다. 모델 계약 통과율을 AI 정확도로 표시하지 않는다.

에이전트는 단순 파일 tail 방식이므로 전송 실패·로테이션·UTF-8 경계에서 손실 가능성이 있다. 운영 전 재전송 큐와 로그 처리 검증을 보완해야 한다.
