# OpsMate 요구사항분석서

OpsMate는 지표 확인, 장애 분류, 매뉴얼 탐색, 처리 이력 기록을 하나의 관제 흐름으로 연결하는 포트폴리오용 시스템이다. 실제 수집 데이터와 가상 데모를 구분하고 AI 제안을 운영자가 검토하도록 설계했다.

## 개발 배경과 해결 대상

운영자는 지표, 로그, 대응 매뉴얼을 서로 다른 화면에서 확인할 때 장애 시점의 맥락을 놓치기 쉽다. 이 프로젝트는 출처가 표시된 지표와 장애 이력을 한 화면에서 확인하고, 관련 매뉴얼을 찾는 작업을 지원한다.

현업 장애 감소 효과나 대응 시간 단축은 측정하지 않았다. 이번 결과물의 수용 기준은 실행 가능성, 데이터 출처 구분, 권한 분리, 근거 인용, 재현 가능한 테스트다.

## 사용자와 운영 시나리오

관리자는 계정·역할·서버·수집 설정을 관리한다. 운영자는 지표와 로그를 확인하고 장애 분석 및 처리 메모를 남긴다. 조회자는 대시보드·로그·매뉴얼·운영 보고서를 열람한다.

대표 시나리오는 가상 디스크 공간 부족 감지 → 장애 상세 조회 → 매뉴얼 및 AI 분석 확인 → 담당자 승인 후 외부에서 수동 조치 → 해결 메모 기록이다. 시스템 자체는 삭제나 재시작을 실행하지 않는다.

| 구분 | 필요 작업 | 권한 범위 |
| --- | --- | --- |
| 관리자 | 서버 등록·계정 운영·감사 | 모든 관리 기능 |
| 운영자 | 장애 확인·분석·해결 | 운영 API |
| 조회자 | 현재 상태와 보고서 확인 | 읽기 전용 |

## 비기능 요구와 제외 범위

Node.js 24, SQLite, 외부 CDN 없는 웹 화면을 기본 실행 환경으로 한다. MariaDB 어댑터와 Docker 실행 설정을 확장 지점으로 제공한다. Redis, 다중 인스턴스, 자동 복구, 이메일·메신저 알림은 이번 범위에 포함하지 않는다.

보안은 scrypt 비밀번호 해시, 서버 측 RBAC, 세션 토큰 해시, Origin 검사, 크기 제한, 매개변수 SQL, 인증 WebSocket, 감사 로그를 포함한다. 운영용 TLS 프록시, 계정 복구, MFA, 장기 부하 검증은 별도 운영 구축 과제다.

외부 호스트 전체에 대한 자동 탐색은 수행하지 않는다. 원격 호스트는 관리자가 등록하고 에이전트가 능동적으로 지표를 전송한다.
