## 선후 관계와 완료 기준

인증·DB → 수집·장애 → API·화면 → 검색·생성 → 테스트 → 문서 증빙 → 원격 동기화 → ZIP 순서로 검증한다. 화면과 문서는 기능 테스트 증빙을 반영하며 변환 후 무결성과 잘림을 확인한다.

XLSX 일정표의 기간은 종료일에서 시작일을 뺀 값에 1을 더한 달력 일수다. 추후 작업은 날짜와 기간을 비워 두며 임의의 완료 예정일을 넣지 않는다.

동일 날짜 작업의 기간 합은 인일이나 총 소요 시간을 뜻하지 않는다. 실제 개발 소요 시간이나 일정 준수율을 측정한 자료로 사용하지 않는다.
