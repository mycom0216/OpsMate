# 메모리 사용률 상승 대응
분류 MEMORY RAM 메모리. RAM 90% 이상을 경고로 감지한다.
캐시 사용과 실제 메모리 압박을 구분하고 프로세스별 증가 추이와 OOM 로그를 확인한다.
원인 후보는 메모리 누수, 과도한 동시 요청, 캐시 증가다. 현재 수치만으로 누수를 확정하지 않는다.
운영자 승인 후 요청 제한, 용량 증설 또는 검증된 배포 롤백을 검토한다.
재시작 전 증거를 보존하고 복구 후 지속적으로 사용률을 확인한다.

## 구조화 대응 근거
- 원인: 메모리 누수로 사용률이 증가했을 가능성
- 원인: 과도한 동시 요청이나 캐시 증가로 사용률이 증가했을 가능성
- 확인: 프로세스별 메모리 증가 추이와 OOM 로그를 확인한다.
- 확인: 캐시 사용과 실제 메모리 압박을 구분해 확인한다.
- 대응: 담당자 승인 후 요청 제한이나 용량 증설을 검토한다.
- 대응: 담당자 승인 후 검증된 배포 롤백을 검토한다.
