# CPU 사용률 상승 대응
분류 CPU. CPU 사용률 85% 이상을 경고로 감지한다. 순간적인 부하와 지속 부하를 구분한다.
운영자는 최근 지표 추이, 프로세스별 사용량, 배포 시점, 요청량을 읽기 전용으로 확인한다.
원인 후보는 트래픽 급증, 반복 작업, 비효율 쿼리다. 지표만으로 원인을 확정하지 않는다.
대응은 담당자 승인 후 트래픽 분산 또는 문제 배포 롤백을 검토한다. 재시작을 자동 실행하지 않는다.
복구 후 사용률과 서비스 응답 상태를 확인하고 처리 기록을 남긴다.

## 구조화 대응 근거
- 원인: 트래픽 급증으로 CPU 부하가 증가했을 가능성
- 원인: 반복 작업 또는 비효율 쿼리로 CPU 부하가 증가했을 가능성
- 확인: 최근 CPU 지표 추이와 프로세스별 사용량을 읽기 전용으로 확인한다.
- 확인: 배포 시점과 요청량 변화를 확인한다.
- 대응: 담당자 승인 후 트래픽 분산을 검토한다.
- 대응: 담당자 승인 후 문제 배포의 롤백을 검토한다.
