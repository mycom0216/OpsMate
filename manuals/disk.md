# 디스크 공간 부족 대응
분류 DISK 디스크 저장 공간 no space left on device. Disk 90% 이상을 경고로 감지한다.
운영자는 파일시스템별 잔여 공간, 로그 증가량, inode, 보존 정책을 확인한다.
원인 후보는 로그 누적, 임시 파일, 대용량 산출물이다. 데이터 손상 여부는 별도 확인한다.
운영자 승인과 백업 확인 후 보존 기간이 지난 로그 정리 또는 볼륨 확장을 검토한다.
AI는 삭제 명령을 실행하지 않는다. 복구 후 여유 공간과 서비스 쓰기 성공 여부를 기록한다.

## 구조화 대응 근거
- 원인: 로그 누적으로 디스크 공간이 부족해졌을 가능성
- 원인: 임시 파일이나 대용량 산출물로 공간이 부족해졌을 가능성
- 확인: 파일시스템의 여유 공간과 로그 증가량 및 inode를 확인한다.
- 확인: 백업과 파일 보존 정책을 확인한다.
- 대응: 담당자 승인과 백업 확인 후 보존 기간이 지난 로그의 정리를 검토한다.
- 대응: 담당자 승인 후 볼륨 확장을 검토한다.
