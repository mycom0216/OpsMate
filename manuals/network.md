# 네트워크 및 수집 중단 대응
분류 HEARTBEAT NETWORK 네트워크 연결 단절 수집 신호 없음 timeout.
60초 이상 수집이 없으면 수집 중단 장애를 생성한다. 장비 장애로 즉시 단정하지 않는다.
에이전트 실행 여부, DNS, TLS, 방화벽, 수집 토큰, 시간 동기화를 읽기 전용으로 확인한다.
수신량 송신량은 바이트/초이며 링크 속도 또는 패킷 손실률이 아니다.
운영자 승인 후 연결 설정과 에이전트를 복구하고 새 수집 시간을 확인한다.

## 구조화 대응 근거
- 원인: 에이전트 중단으로 수집 신호가 끊겼을 가능성
- 원인: DNS TLS 방화벽 또는 수집 토큰 문제로 전송이 중단됐을 가능성
- 확인: 에이전트 실행 상태와 마지막 수집 시각을 확인한다.
- 확인: DNS TLS 방화벽 수집 토큰을 읽기 전용으로 확인한다.
- 대응: 담당자 승인 후 잘못된 연결 설정을 수정한다.
- 대응: 담당자 승인 후 에이전트를 복구하고 새 수집 시각을 확인한다.
